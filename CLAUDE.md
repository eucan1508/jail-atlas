# Working notes for this repository

- When the owner asks to add places ("yer ekle"), take the next counties from
  `docs/expansion-priority.md`, in order, and update each entry's Status there as part of the
  change.
- Before starting, tell the owner which counties are next on the list (and which ones were skipped,
  and why).
- When the list reaches a new state, ask the owner for approval before adding it.
- When the list runs out, tell the owner and build a new ranked list together before adding more
  places.
